Project 02

3D F1 Portfolio

Status: green flag

01Design theme

A performance-focused portfolio inspired by motorsport engineering. The home page is a real-time 3D night circuit where every career milestone is a stop on the lap, marked by a trackside LED board. Scrolling drives a procedurally modelled F1 car from stop to stop, while a live telemetry HUD tracks turn, speed and lap progress.

023D engine

Built with Three.js and no build step. The car is sculpted in code from lofted cross-sections, aerofoil wing elements and lathed Pirelli tyres. The circuit, grandstands, floodlights and boards are generated too, lit with physically based materials, soft shadows, an environment map and bloom. The camera cuts between parked three-quarter shots and a chase cam as you scroll.

03UI and accessibility

Content sits on glass panels over the scene, laid out with CSS Grid and Flexbox and themed with CSS variables. It respects reduced-motion settings and falls back to video when WebGL is unavailable.
