Career Predictor

Status: purple sector

01Project description

The Career Predictor App was built to bridge the gap between student skills and industry requirements. Using a data-driven approach, the system analyses user input to recommend the most likely career paths.

02Technical usage

The backend uses Python for the logic and SQL to manage the dataset of career parameters. The aim was a program that stores user answers and returns a matching career path.
